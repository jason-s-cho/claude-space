# claude-space

## schedule/ — 나의 일정 수첩

브라우저에서 쓰는 개인 일정 관리 도구입니다.

- 월간 달력(일요일 시작, 대한민국 공휴일·대체공휴일 표시)
- 날짜를 누르면 그날의 일정 목록, 두 번 누르면 새 일정 추가
- 일정마다 시간·분류(업무/개인/건강/약속/기타)·메모, 완료 체크
- 오늘 남은 일정·앞으로 7일 요약, 검색
- Google 캘린더 연동: 달력에 Google 캘린더 일정을 함께 표시(5분마다 갱신), 새 일정을 Google 캘린더에도 추가하고, 수정·삭제도 양쪽에 반영
- 일정 백업: 화면 아래 **내보내기**로 일정을 JSON 파일로 저장하고, **가져오기**로 불러옵니다. 가져오기는 기존 일정을 지우거나 덮어쓰지 않고, 같은 날짜·시간·제목이 이미 있으면 건너뜁니다. (PC나 브라우저를 옮길 때 사용. Google 캘린더 연결 정보는 백업에 포함되지 않습니다.)
- 단축키: `n` 새 일정, `Alt+←/→` 달 이동

claude.ai Artifact로 열면 일정이 서버에 저장되어 어느 기기에서나 같은 일정이 보입니다.
`schedule/index.html`을 브라우저로 직접 열면 그 브라우저의 localStorage에 저장됩니다.

Google 캘린더 연동은 claude.ai Artifact에서 Google Calendar 커넥터가 연결되어 있을 때만 동작합니다.

## desktop/ — 데스크톱 앱 (Electron)

`schedule/index.html`을 그대로 감싸서 Windows / macOS / Linux 설치형 앱으로 만듭니다.
빌드할 때 `schedule/index.html`이 `desktop/app/`으로 복사되므로, 웹 버전을 고치면 데스크톱 버전에도 반영됩니다.

**내 PC에서 실행해 보기**

```bash
cd desktop
npm install
npm start
```

**설치 파일 만들기**

- 내 PC에서: `npm run dist` → `desktop/dist/`에 설치 파일 생성 (자기 OS용만 만들어짐)
- GitHub에서 3개 OS 한꺼번에: Actions 탭 → *Desktop build* → Run workflow.
  `git tag desktop-v0.1.0 && git push origin desktop-v0.1.0` 하면 Releases에 설치 파일이 올라갑니다.

**참고**

- Google 캘린더 연동은 claude.ai Artifact에서만 동작하며, 데스크톱 앱에서는 꺼진 상태로 일정 수첩 기능만 사용됩니다.
- 일정은 설치한 PC의 앱 데이터에 저장됩니다. PC마다 따로 저장되며 서로 동기화되지 않으니, PC를 옮길 때는 **내보내기 → 가져오기**를 쓰세요.
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen / macOS Gatekeeper 경고가 뜰 수 있습니다.
- 앱 아이콘 원본은 `desktop/assets/icon.svg`, 앱이 쓰는 이미지는 같은 폴더의 `icon.png`(1024×1024)입니다. 아이콘을 바꾸려면 이 PNG를 교체하세요. (Windows·Mac용 아이콘은 빌드할 때 자동 변환됩니다.)
- 달력 글꼴은 온라인일 때 Google Fonts를 쓰고, 오프라인이면 시스템 글꼴로 대체됩니다.

## doc-manager/ — 문서 보관함 (Electron)

내가 만든 문서를 한 폴더에 모아 두면, 파일을 읽어서 **자동으로 분류하고 태그를 붙여 주는** 데스크톱 앱입니다.
폴더 안의 문서 파일을 고치지는 않으며(내가 '옮기기'를 누를 때만 옮김), 분류 결과·태그·메모는 문서 폴더 안 `.docmanager/`에 저장됩니다.

**자동 분류**

| 분류 | 세부 |
|---|---|
| 국가과제·지원사업 | 1 공고·수요조사 · 2 사업계획서 · 3 선정·협약 · 4 수행·회의 · 5 보고서 · 6 정산·증빙 · 기타 |
| 회사 증빙 | 기본 서류(사업자등록증·등기부등본·정관·주주명부·인감) · 인증·확인서(벤처·연구소·이노비즈·소부장·ISO 등) · 실적·재무(수출실적·재무제표·납세증명·4대보험 명부) · 인사(재직·경력·졸업 증명서, 자격증, 이력서, 근로계약서, 급여명세서) |
| 지식재산 | 특허 출원(출원서·명세서·의견서) · 특허 등록(특허증·등록공보) · 상표·디자인 |
| 회사소개 | IR·투자 · 회사소개서 |
| 홍보 | 홈페이지 · 카탈로그·브로셔 |
| 기술·시장 분석 | 기술동향, 경쟁사, 시장조사, ○○_Analysis |
| 고객사·협력사 | 요청·제출 자료 (등록한 회사마다) |
| 구매·견적 | 장비 견적, 발주, 구매 |
| 미분류 | 단서를 못 찾은 문서 (직접 골라 주세요) |

- 파일 이름 → 폴더 이름 → 본문 앞부분 → 본문 순으로 키워드를 찾아 점수를 매깁니다. 문서를 고르면 **분류 근거**가 나오고, 틀렸으면 직접 바꿀 수 있습니다. 직접 고친 분류·태그·메모는 파일 이름을 바꾸거나 옮겨도 따라갑니다.
- **과제 등록**(설정 → 과제): `2024 K-방산 제품고도화 = K-방산, 제품고도화`처럼 적어 두면, 그 과제 문서를 `국가과제·지원사업 / 과제 이름 / 단계` 폴더로 정리하고 **거르기**의 '과제'에서 모아 볼 수 있습니다. 폴더 이름의 `[완료]`도 알아봅니다.
- 국가과제 단서(과제 이름, 주관기관, 사업비, 지원사업 등)가 없으면 '회의록', '정산' 같은 흔한 단어만으로는 국가과제로 보지 않습니다.
- **개인정보 서류**(등기부등본·주주명부, 근로계약서·연봉계약서·급여명세서·원천징수영수증·인사기록카드, 가리지 않은 주민등록번호가 보이는 문서)에는 'AI제외' 태그가 자동으로 붙어 Claude 에 보내지 않습니다. 보내도 되는 문서는 문서 화면에서 'Claude 에 보내지 않기'를 끄면 됩니다.
- 대문자 약어(IR, RAM, NDA)는 대소문자까지 맞아야 합니다. (`graphene_ir_sensitivity`의 ir은 IR 자료가 아님)

**자동 태그**

- 연도: 파일·폴더 이름의 `2025`, `25년`, `20250508`, **`250926`(YYMMDD)**, 없으면 본문에 가장 많이 나온 연도
- 기관(산업부·중기부·과기정통부, KEIT·IITP·TIPA·NIPA·한국연구재단 등), 과제 이름, 고객사 이름, 버전(최종본·초안·수정본·v2), 보고 단계, `[완료]`, 영문 문서
- **기술 분야**(끌 수 있음): 그래핀, 스텔스·RAM, 전자파차폐, 센서, 투명발열체·TCF, PFAS, 라이다, 광전자·포토닉스, 반도체, 방산, 배터리
- **내 태그 규칙**(`염화물: chloride, 염화물`)으로 원하는 태그를 더 붙일 수 있습니다.

**버전 묶기**

- `엠씨케이테크_IR_초안`, `엠씨케이테크_IR_260406`, `엠씨케이테크_IR (2)`처럼 초안·최종·v01·날짜·(2)·사본만 다른 파일을 같은 문서로 묶고, 가장 최근에 고친 것을 **최신본**으로 보여 줍니다.
- 목록에는 최신본 하나만 나오고 옆의 숫자 단추를 누르면 이전 버전이 펼쳐집니다. 문서 오른쪽 '버전 기록'에서 버전 사이를 오갈 수 있고, 이전 버전을 보고 있으면 "더 최신 버전이 있습니다" 안내가 나옵니다.
- 연도가 다르거나(2025 / 2026 수요조사) 국문/영문처럼 내용이 다른 것은 묶지 않습니다. 목록 위 **버전 묶기** 스위치로 끌 수 있습니다.

**새 버전으로 고치기**

- 문서 오른쪽의 **새 버전으로 고치기**를 누르면 같은 폴더에 다음 버전 이름으로 복사하고 바로 엽니다. 원본은 그대로 남습니다.
- 이름은 쓰시던 방식을 따릅니다: `보고서_v01` → `보고서_v02`(같은 문서에 v05가 있으면 v06), `엠씨케이테크_IR_260406` → 오늘 날짜(`…_261009`), 표시가 없으면 `_v2`. 같은 이름이 있으면 번호만 올립니다.
- 새 버전은 분류·태그를 이어받고(메모·즐겨찾기는 그 버전에만), 버전 기록에 자동으로 묶여 최신본이 됩니다.

**문서 넣기 (끌어다 놓기) · 분류별 폴더**

- 문서 폴더를 고르면 그 안에 위 표의 분류별 폴더를 자동으로 만들어 둡니다. 등록한 과제마다 `국가과제·지원사업/과제 이름/1~6 단계` 폴더를, 등록한 고객사마다 `고객사·협력사/회사 이름` 폴더를 만듭니다. 원래 있던 파일은 옮기지 않습니다.
- 새로 만든 문서를 창에 **끌어다 놓거나** **＋ 문서 넣기**로 고르면, 내용을 읽고 분류한 뒤 맞는 분류 폴더에 **복사**합니다. (원본은 그대로. 폴더째 놓아도 됩니다.)
- 원래 있던 폴더 이름도 단서로 씁니다. 예: `…/현대모비스/단가표.xlsx` → `고객사·협력사/현대모비스/`
- 같은 이름이 있으면 덮어쓰지 않고 `이름 (2).docx`로 저장하고, 내용까지 같은 파일은 다시 복사하지 않습니다. 수정한 날짜는 원본 그대로입니다.
- 넣은 뒤에는 '방금 넣은 문서'만 보여 주므로 분류를 바로 확인할 수 있습니다. 분류를 고치면 **📁 ○○ 폴더로 옮기기** 버튼으로 파일을 맞는 폴더로 옮길 수 있습니다. (태그·메모는 따라감)
- 분류 폴더를 쓰지 않으려면 **설정 → 일반 → 끌어다 놓은 파일 저장 위치 → 문서 폴더 바로 아래**를 고르세요.

**할 일 · 왼쪽 메뉴**

- 앱을 켜면 **할 일** 화면이 먼저 나옵니다. 흩어져 있던 알림을 카드로 모았습니다: 다가오는 마감(30일 안), 만료되는 회사 증빙, 대장에 없는 지식재산 번호, 정리할 문서(제자리가 아닌 문서·중복·미분류), 스캔 PDF 글자 읽기, 아직 없는 작성 카드, 이번 주에 바뀐 문서, 최근 Claude 활동. 항목을 누르면 그 지원 건·문서·목록으로 갑니다.
- 왼쪽 '할 일' 옆 숫자는 바로 챙길 것(7일 안·지난 마감, 30일 안 만료 증빙, 대장에 없는 번호)입니다.
- 왼쪽 메뉴는 **업무**(할 일 · 지원 현황 · 지식재산 대장), **문서**(전체 · 즐겨찾기 · 최근 30일 · 방금 넣은 문서 · 저장한 검색), **분류** 셋으로 나뉩니다. 분류 묶음은 접혀 있다가 누르면 펼쳐집니다.
- 과제·연도·파일 형식·태그·키워드로 좁히기는 목록 위 **거르기** 버튼에 모았습니다 (고른 개수가 버튼에 표시됨).

**핵심 키워드**

- 문서마다 본문에 많이 나오는 단어(전자파 차폐, 그래핀 센서 등)를 자동으로 뽑아 오른쪽에 보여 줍니다. 다른 문서에도 흔한 단어는 빼고, 그 문서에서 두드러지는 단어를 고릅니다.
- 키워드를 누르면 같은 단어가 나오는 문서를 모두 찾고, ＋를 누르면 태그로 붙습니다.
- **거르기**의 '키워드'에서 여러 문서에 걸친 주제를 한눈에 볼 수 있습니다.

**검색**

| 검색어 | 뜻 |
|---|---|
| `그래핀 센서` | 두 단어가 모두 있는 문서 |
| `"전자파 차폐"` | 구절 그대로 (띄어쓰기는 무시: "전자파차폐"도 찾음) |
| `그래핀\|graphene` | 둘 중 하나라도 |
| `-초안` | 이 단어가 있는 문서는 빼기 |
| `#KEIT` 또는 `태그:KEIT` | 태그 |
| `분류:보고서` | 분류 이름에 '보고서'가 들어간 것 |
| `연도:2025` | 연도 태그나 수정한 해 |
| `형식:ppt` | word · ppt · excel · pdf · hwp (워드·파워포인트·엑셀·한글도 됨) |
| `폴더:고객사` `이름:최종` `메모:제출` `키워드:그래핀` | 폴더 이름 · 파일 이름 · 메모 · 핵심 키워드 |

- 검색창을 누르면 최근 검색과 위 도움말이 나옵니다.
- **☆ 이 조건 저장**을 누르면 지금 검색어와 왼쪽에서 고른 분류와 거르기에서 고른 태그·형식이 함께 왼쪽 '저장한 검색'에 들어갑니다. (예: `분류:과제보고서 연도:2025 -초안`)

**분류 키워드 편집**

- **설정 → 분류 키워드**에서 분류마다 키워드를 보고, 더하거나 뺄 수 있습니다. 세기는 약함·보통·강함 중에서 고릅니다.
- 문서 오른쪽의 '분류 키워드 고치기'를 누르면 그 문서의 분류 키워드로 바로 갑니다.
- 기본 키워드는 그대로 두고 내가 바꾼 것만 따로 저장하므로, '기본 키워드로 되돌리기'로 언제든 원래대로 돌릴 수 있습니다.

**그 밖의 기능**

- 분류·연도·파일 형식·태그로 걸러 보기, 즐겨찾기, 최근 30일, 메모
- 폴더를 감시해서 새 파일·고친 파일을 자동으로 다시 읽음 (바뀐 파일만 읽음)
- 두 번 누르면 파일 열기, '폴더에서 보기', 지금 보이는 목록을 CSV(엑셀)로 내보내기

**읽을 수 있는 파일**

| 형식 | 본문까지 읽음 | 파일 이름으로만 분류 |
|---|---|---|
| 워드 | .docx, .doc | |
| 파워포인트 | .pptx (슬라이드 노트 포함) | .ppt |
| 엑셀 | .xlsx | .xls |
| PDF | .pdf (글자가 있는 PDF) | 스캔한 PDF |
| 한글 | .hwp, .hwpx | 암호·배포용 .hwp는 앞부분(미리보기)만, HWP 3.0 이전 문서는 이름만 |

**실행 · 설치 파일 만들기**

```bash
cd doc-manager
npm install
npm start        # 실행
npm test         # 분류 규칙 테스트
npm run dist     # 내 OS용 설치 파일 → doc-manager/dist/
```

GitHub에서 3개 OS 설치 파일을 한꺼번에 만들려면 Actions 탭 → *Doc manager build* → Run workflow,
또는 `git tag docmanager-v0.1.0 && git push origin docmanager-v0.1.0` (Releases에 올라감).

기본 분류 키워드는 `doc-manager/lib/classify.js`의 `KEYWORDS`에 있습니다. 보통은 앱의 **설정 → 분류 키워드**에서 고치면 됩니다.

**Claude 연결 (커넥터)**

- **설정 → Claude 연결 → 연결**을 누르면 Claude 데스크톱 앱 설정(`claude_desktop_config.json`)에 문서 보관함 커넥터를 넣습니다. 다른 커넥터 설정은 그대로 두고, 원래 파일은 `.bak`으로 남깁니다. **Claude 앱을 완전히 종료했다가 다시 켜면** 적용됩니다.
- Claude 에게 이렇게 말할 수 있습니다: "작년 K-방산 최종보고서에서 성과 부분 찾아서 올해 사업계획서 초안에 맞게 고쳐 줘", "그래핀 스텔스 관련 IR 자료 중 최신본 요약해 줘", "이 계획서에 재사용할 만한 예전 자료 찾아 줘".
- Claude 가 쓰는 도구: 보관함 둘러보기 · 문서 검색(검색 문법 그대로, 기본은 최신본만) · 문서 읽기(긴 문서는 이어 읽기, 한글 포함) · 버전 기록 · 관련 문서 찾기 · 회사 지식 카드 읽기·저장 · 양식 칸 보기·**양식 채우기** · **새 버전으로 저장** · 새 버전 복사본 만들기(Claude Code 용).
- **기존 파일은 고치거나 지울 수 없습니다.** Claude 가 고친 결과는 항상 같은 폴더에 다음 버전 이름으로 새로 저장되고, 앱이 자동으로 분류해 버전 기록에 묶습니다.
- **Claude 에 보내지 않을 문서**: 설정에서 분류를 고르거나, 문서 오른쪽 **Claude 에 보내지 않기**를 켜면('AI제외' 태그) Claude 가 검색·읽기를 할 수 없습니다. 이 설정은 문서 폴더를 따라갑니다.
- Claude 가 무엇을 찾고 읽고 만들었는지는 **최근 Claude 사용 기록**(`.docmanager/ai-log.jsonl`)에 남습니다.
- Claude Code 에서는 같은 탭의 명령을 터미널에 한 번 붙여 넣으면 됩니다.
- 커넥터는 앱 실행 파일을 그대로 사용하므로 Node.js 를 따로 설치할 필요가 없습니다. 앱이 꺼져 있어도 동작하지만, 그동안 새로 넣은 파일은 앱을 켜서 색인한 뒤에 검색됩니다.
- Claude 가 읽은 문서 내용은 Claude(Anthropic)로 전송됩니다. 민감한 문서는 위의 제외 설정을 써 주세요.

**지원 현황 (지원 건 · 단계별 결과)**

- 한 주제(기술)를 한 사업에 낸 것을 **지원 건** 하나로 기록합니다. 같은 주제를 다른 사업에도 냈으면 지원 건을 따로 만듭니다.
- 지원 건마다 **단계**(예: 수요조사 제출 → RFP 반영 → 사업계획서 제출 → 서류평가 → 발표평가 → 선정·협약)별로 결과(진행·통과·탈락·제외), 날짜, **평가 의견·탈락 사유**, 관련 문서를 남깁니다.
- **단계 틀**: 사업 유형마다 기본 단계 목록을 둡니다(국가 R&D 수요조사부터 / 공고부터, 지원사업 등). 틀은 고치거나 더할 수 있고, 지원 건마다 단계를 더하고 빼고 이름·순서를 바꿀 수 있습니다.
- 왼쪽 **지원 현황**에서 지원 건을 단계 막대로 한눈에 보고(진행 중·선정·탈락으로 거르기), 문서 화면의 **지원 건** 카드에서 문서를 지원 건 단계에 연결합니다. 문서를 옮겨도 연결은 따라갑니다.
- 지원 건은 **사업명별로 묶여** 보입니다 (예: 소재부품기술개발사업, 암묵지 사업, 국방반도체 R&D 사업). 왼쪽 지원 현황 아래 사업명을 누르면 그 사업의 지원 건만 보고, 가운데 목록의 사업 제목줄을 누르면 접고 펼칩니다. 사업명은 이미 쓴 이름을 목록에서 고를 수 있고, 띄어쓰기 차이는 하나로 맞춰 같은 사업으로 묶습니다.
- **사업 자료**: 공고문·RFP·작성 양식·평가 기준처럼 받은 자료를 사업에 붙여 둡니다. 왼쪽에서 사업명을 누르면 오른쪽에 사업 자료 칸이 나옵니다. 종류를 고르고 **파일 넣기**(또는 칸에 끌어다 놓기)를 하면 `국가과제·지원사업/1 공고·수요조사/사업명` 폴더에 넣고 바로 연결합니다. 이미 보관함에 있는 문서는 **보관함에서 고르기**로 연결합니다. 사업에 붙인 자료는 그 사업의 지원 건 모두가 같이 보고, 한 과제에만 해당하는 자료(그 과제의 RFP 등)는 지원 건의 **이 과제만의 자료**에 붙입니다. 자료 이름을 누르면 파일이 열립니다.
- Claude 는 사업에 낼 문서를 쓰기 전에 사업 자료(get_program)를 먼저 읽고 공고의 요구 사항·평가 항목에 맞춰 씁니다.

**작성 카드 (주제 카드 · 사업 카드 · 작성 가이드)**

양식은 사업마다 다르고, 같은 주제를 여러 사업에 내기도 합니다. 그래서 Claude 는 문서를 쓸 때 네 가지를 겹쳐 봅니다: **양식**(칸 구성) × **주제 카드**(기술 내용) × **사업 카드**(그 사업이 보는 것) × **작성 가이드**(문서 종류별·항목 종류별 쓰는 법).

- **주제 카드** (`Claude 지식/주제/주제.md`): 한 줄 정의, 핵심 수치, 차별점, 선행 실적, 시장, 사업화 단서, 지원 이력과 교훈, 검증된 문장. 사업이 달라도 같이 씁니다.
- **사업 카드** (`Claude 지식/사업/사업명.md`): 사업 개요·일정·자격, 평가 항목과 배점, 강조점, 양식 특징, 우리 지원 이력과 교훈. 공고문·평가 기준(사업 자료)으로 만듭니다.
- **작성 가이드** (`Claude 지식/작성 가이드/수요조사서.md`, `…/사업계획서.md`): 문서 종류마다 한 장. 수요조사서는 짧고 RFP 로 반영되는 것이 목표라 기술명·필요성·정량 목표·개발 범위·동향·활용 위주로, 사업계획서는 평가 배점에 맞춰 요약·목표·필요성·현황·개발 내용·역량·추진 체계·사업화·기대 효과·연구비 위주로 우리 회사가 통과한 문서에서 쓴 방식을 정리합니다. 지원 건 화면에는 다음에 쓸 문서의 가이드가 보입니다 (예전 한 장짜리 `작성 가이드.md` 는 사업계획서 가이드로 옮겨집니다).
- 지원 건을 열면 **문서 쓰기** 칸에 이 건의 카드가 있는지 보이고, **Claude 로 만들기**를 누르면 요청 문장이 복사됩니다. **직접 쓰기 / 보기·고치기**로 앱에서 바로 고칠 수 있습니다. 설정 > Claude 연결의 **작성 카드**에 전체 목록이 있습니다.
- 맨 아래 문장(예: "문서 보관함의 '…' 지원 건(소재부품기술개발사업)으로 수요조사서를 써 줘")을 Claude 데스크톱에 붙여 넣으면 Claude 가 회사 지식 카드 → 지원 이력·탈락 사유 → 사업 자료 → 카드 → 양식 순서로 읽고, **칸별 요약을 먼저 보여 준 뒤** 양식을 새 파일로 채우고 지원 건에 연결합니다. Claude 데스크톱 '+' 메뉴의 **사업 문서 쓰기 / 주제 카드 만들기 / 사업 카드 만들기 / 작성 가이드 만들기**로 시작해도 됩니다.
- 카드는 저장할 때마다 이전 내용을 기록으로 남기고, **사용자 메모** 칸은 Claude 가 고치지 않습니다.

**회사 증빙: 유효기간 · 제출 서류 꾸러미**

- 회사 증빙 문서는 **종류**(사업자등록증, 벤처기업확인서, 국세완납증명서 …)를 알아보고, 같은 종류가 여러 장이면 발급일이 가장 늦은 것을 **최신본**으로 봅니다 (예전 것은 목록에 '이전 발급본').
- 문서 본문(스캔본은 OCR 후)에서 **발급일·유효기간**을 찾아 채우고, 문서 화면의 **회사 증빙** 칸에서 고칠 수 있습니다. 최신본의 유효기간이 **30일·7일 전과 당일**에 알려 주고, 목록에 '만료 D-12', '만료됨'이 붙습니다.
- 지원 건의 **제출 서류** 칸에서 공고가 요구하는 서류를 고르면, **최신본 모아 폴더 만들기**로 고른 순서대로 번호를 붙여(`01_사업자등록증.pdf` …) 원하는 곳에 새 폴더로 복사합니다. 보관함에 없거나 만료된 서류는 알려 줍니다.
- Claude 는 list_certificates 로 종류별 최신본·유효기간을 보고, 양식의 사업자등록번호·인증번호 같은 칸을 채우거나 빠진·만료된 서류를 알려 줍니다 (AI 제외인 등기부등본 등은 있다는 것만 압니다).

**지식재산 대장 (특허·실용신안·상표·디자인)**

- 왼쪽 **지식재산 대장**에서 한 건씩 관리합니다: 명칭, 출원번호·출원일, 공개번호, 등록번호·등록일, 상태(출원·공개·등록·거절·포기·소멸), 출원인, 발명자, 관련 주제·과제, 문서(출원서·명세서·의견서·등록증).
- 지식재산으로 분류된 문서(스캔본은 OCR 후)에서 **출원번호·등록번호·명칭·날짜를 찾아** 대장에 없는 것을 위에 보여 주고, **대장에 넣기**로 바로 넣습니다. 번호 앞자리로 종류를 알아보고(10 특허, 20 실용신안, 30 디자인, 40 상표), 등록번호가 생기면 상태가 등록으로 바뀝니다.
- **표로 복사**를 누르면 보이는 목록이 표(구분·명칭·출원번호·출원일·등록번호·등록일·상태·출원인·발명자)로 복사되어 사업계획서·엑셀에 바로 붙여 넣을 수 있습니다.
- Claude 는 사업계획서의 지식재산·선행 실적 표와 주제 카드의 실적을 이 대장(list_ip)에서 가져오고, 문서를 읽어 대장을 채울 수 있습니다(record_ip). 연차료 알림은 두지 않습니다(특허사무소가 챙김). 대장은 `.docmanager/ip.json` 에 저장됩니다.

**마감 알림**

- 지원 건의 단계마다 **마감**(날짜, 필요하면 시각)을 적습니다. 공고문을 읽은 Claude 가 접수 마감을 찾아 적어 줄 수도 있습니다.
- 지원 현황 맨 위에 **다가오는 마감**(30일 안, 지난 것 포함)이 D-day 와 함께 보이고, 목록의 지원 건에도 D-day 가 붙습니다.
- 마감 **7일·3일·1일 전과 당일**에 윈도우 알림을 띄웁니다 (누르면 그 지원 건이 열림). 설정 > 일반에서 끌 수 있습니다.
- 단계의 **구글 캘린더**를 누르면 브라우저에 일정 추가 화면이 열리고, **일정 파일**을 누르면 아웃룩·윈도우 일정에 넣을 수 있습니다. **모든 마감 내보내기**는 .ics 파일 하나로 저장합니다 (구글 캘린더 설정 > 가져오기). 일정에는 3일 전·1일 전 알림이 들어 있습니다.

**스캔 PDF 글자 읽기 (OCR)**

- 글자가 없는 스캔 PDF(공고문·받은 서류 등)는 **윈도우에 들어 있는 글자 인식**(한국어)으로 읽습니다. 따로 설치할 것이 없습니다.
- 문서 폴더를 훑은 뒤 스캔 PDF 를 하나씩 뒤에서 읽습니다 (문서마다 앞 60쪽, 왼쪽 아래에 진행 표시). 문서 화면의 **지금 글자 읽기 / 나머지 쪽도 읽기**로 바로 읽을 수도 있습니다.
- 읽은 글자로 검색·자동 분류가 되고 Claude 도 내용을 읽습니다 (인식 오류가 있을 수 있어 Claude 는 수치를 확인하라고 안내받습니다).
- 결과는 `.docmanager/ocr/` 에 파일 내용 지문으로 남아, 이름을 바꾸거나 다른 PC에서 열어도 다시 읽지 않습니다.
- "OCR 언어가 없습니다"가 나오면: 윈도우 설정 > 시간 및 언어 > 언어 및 지역 > 한국어 > 언어 옵션에서 **광학 문자 인식**을 설치하세요. 자동 읽기는 설정 > 일반에서 끌 수 있습니다.
- Claude 도 지원 건을 읽고 기록합니다(지원 건 목록·자세히·기록). 수요조사서·계획서를 쓸 때 같은 주제·같은 사업의 탈락 단계와 사유를 먼저 보고 같은 약점을 피합니다.
- 저장 위치: 문서 폴더 `.docmanager/applications.json` (다른 PC에서도 그대로).

**제자리가 아닌 문서 모두 옮기기**

- 분류에 맞는 폴더(또는 그 아래 하위 폴더)에 있지 않은 문서는 **할 일 → 정리할 문서**의 '제자리가 아닌 문서'에 모입니다.
- **모두 제자리로 옮기기**를 누르면 "지금 폴더 → 옮길 폴더" 목록이 나오고, 체크한 것만 옮깁니다. 미분류 문서는 처음엔 빠져 있습니다. 태그·메모는 따라가고, 같은 내용의 파일이 이미 있으면 옮기지 않고 알려 줍니다.

**중복 정리**

- 이름·위치와 상관없이 **내용이 완전히 같은 파일**은 **할 일 → 정리할 문서**의 '내용이 똑같은 파일'에 묶여 보이고, 문서 화면에도 "내용이 똑같은 파일이 N개 더 있습니다"로 알려 줍니다.
- **중복 정리**를 누르면 묶음마다 남길 파일 하나를 고르고(제자리 → 태그·메모 있는 것 → 최신 버전 이름 → 먼저 만든 것 순으로 미리 골라 둠), 나머지는 휴지통으로 보냅니다. 보내기 직전에 내용이 같은지 다시 확인하고, 사본의 태그·메모는 남긴 파일로 옮깁니다.
- 제자리로 옮길 때 같은 파일이 이미 제자리에 있으면 옮기기 목록에서 빼고 "중복 정리로" 표시합니다.

**문서 지우기**

- 문서를 고른 뒤 오른쪽 위 **휴지통 아이콘**을 누르면, 한 번 더 확인한 뒤 파일을 **휴지통**으로 옮깁니다. 휴지통에서 되살릴 수 있지만 이 앱에서 붙인 태그·메모·직접 고른 분류는 사라집니다.
- Claude 커넥터에는 지우는 기능이 없습니다.

**양식 채우기 (워드 .docx · 한글 .hwpx)**

- 기관 양식을 Claude 가 새로 만들지 않고, **원래 양식 파일의 글자만 채워** 새 파일로 저장합니다. 글꼴·크기·표·칸 크기·문단 모양·누름틀은 그대로라 바로 제출할 수 있습니다. 원본은 바뀌지 않습니다.
- Claude 에게 이렇게 말하면 됩니다: "문서 보관함의 2027 수요조사서 양식.hwpx 를 지식 카드와 작년 탄소·나노 수요조사서를 참고해서 채워 줘. 파일 이름은 2027_수요조사서_엠씨케이테크로".
- Claude 는 **양식 칸 보기**로 칸 번호(문단 p3, 표 칸 t1.r2.c3)와 표 제목(같은 행 왼쪽·같은 열 위)을 확인하고, **양식 채우기**로 한 번에 채웁니다. 줄바꿈은 같은 모양의 문단으로 늘어나고, 회색·기울임 안내 문구 자리는 보통 글자 모양으로 바꿔 씁니다.
- 새 파일은 양식과 같은 폴더에 주어진 이름(없으면 `…_v2`)으로 저장되고, 앱이 자동으로 분류합니다.
- **표 행 늘리기**: 참여인력·장비·예산·특허 목록처럼 행이 모자란 표는 빈 행 하나를 본으로 복사해 필요한 만큼 늘려 채웁니다(합계 행 등은 아래로 밀립니다). 세로로 합친 칸이 걸친 행은 본으로 쓸 수 없습니다.
- **체크 표시**: "□ 해당 □ 미해당" 같은 칸은 고른 보기 앞의 □ 만 ■ 로 바꿉니다(글자 모양 그대로, 워드 체크 상자 컨트롤도 체크됨).
- 한글 **.hwp**·옛 워드 **.doc** 양식은 아래 **다른 형식으로 저장**으로 .hwpx/.docx 사본을 만든 뒤 씁니다(Claude 에게 맡기면 알아서 바꿉니다).
- 지금은 본문(표 포함)만 채웁니다. 머리말·꼬리말, 글상자·도형 안의 글자는 바꾸지 않습니다.

**다른 형식으로 저장 (윈도우, 한글·워드 필요)**

- 문서 화면의 **다른 형식으로 저장** 줄에서 고릅니다: 한글 .hwp → **hwpx**(양식 채우기용)·**PDF**, 한글 .hwpx → PDF, 워드 .doc → docx·PDF, 워드 .docx → PDF.
- 이 PC에 설치된 한글·워드를 화면 없이 실행해 같은 폴더에 새 파일을 만듭니다. 원본은 그대로이고, 같은 이름이 있으면 "이름 (2).pdf" 처럼 비켜 갑니다.
- 한글은 보안 설정에 따라 **'접근 허용' 창**을 띄웁니다. [접근 허용] 또는 [모두 허용]을 눌러야 진행됩니다.
- Claude 도 같은 기능(형식 바꾸기)을 씁니다: .hwp 양식을 받으면 hwpx 로 바꿔 채우고, 제출용 PDF 를 만들 수 있습니다.

**버전 비교**

- 버전 기록의 이전 버전 옆 **비교**(또는 "더 최신 버전이 있습니다" 안내의 **바뀐 곳 비교**)를 누르면, 두 버전의 본문을 문단 단위로 비교해 고친 곳은 낱말 단위로, 추가·삭제된 문단은 색으로 보여 줍니다. 같은 문단이 길게 이어지면 접어 둡니다.
- 위쪽 **바뀐 숫자**에 "300→200", "1.2→1.4" 처럼 숫자가 달라진 곳만 모아 보여 줘서, Claude 가 고친 버전의 수치 실수를 빨리 잡을 수 있습니다.
- Claude 도 새 버전을 만든 뒤 같은 비교(바뀐 곳 비교)로 무엇을 바꿨는지 알려 줍니다.
- 본문 글자만 비교합니다(서식·그림·표 모양은 제외).

**회사 지식 카드**

- Claude 가 보관함 문서를 읽고 회사의 핵심 사실(회사 개요, 핵심 기술·제품, 대표 성능 수치, 과제 이력, 고객사, 자주 쓰는 표현, 확인 필요 항목)을 정리해 **문서 폴더/`Claude 지식/회사 지식 카드.md`** 에 둡니다. 사실마다 근거 문서를 [출처]로 붙이고, 문서끼리 값이 다르면 '확인 필요'에 적습니다.
- 만들기: Claude 데스크톱 일반 채팅에서 "문서 보관함의 자료로 회사 지식 카드를 만들어 줘" (또는 `+` 메뉴 → 문서 보관함 → 회사 지식 카드 만들기). 문서가 늘면 "회사 지식 카드 새로 고쳐 줘".
- Claude 는 문서를 쓰거나 고치기 전에 이 카드를 먼저 읽고, 카드의 사실·수치·표현을 우선 씁니다.
- 고치기: **설정 → Claude 연결 → 회사 지식 카드 → 직접 고치기**, 또는 메모장 등으로 파일을 직접 엽니다. 맨 아래 **사용자 메모**는 Claude 가 새로 고칠 때도 그대로 남습니다.
- 바꿀 때마다 이전 내용을 `.docmanager/knowledge-history/` 에 남깁니다 (최근 30개).

**분류 정보 저장 위치 (다른 PC에서도 그대로)**

- 직접 고친 분류·태그·메모, 과제·고객사 목록, 태그 규칙, 분류 키워드, 저장한 검색은 **문서 폴더 안 `.docmanager/`** 에 저장합니다. (윈도우에서는 숨김 폴더)
- 그래서 폴더를 다른 곳으로 옮기거나, Google Drive·OneDrive 등으로 동기화해 **다른 PC에서 열어도 그대로** 보입니다. 경로나 드라이브 문자가 달라도 됩니다.
- 문서 **본문(검색용 글자)은 문서 폴더에 두지 않고 이 PC의 앱 데이터 폴더(`textcache/`)에 따로** 둡니다. 그래서 `.docmanager/index.json` 은 문서 수천 개에도 몇 MB 이고, 태그 하나를 고쳐도 작은 파일만 다시 저장·동기화합니다. 다른 PC에서 처음 열면 본문만 한 번 다시 읽습니다(분류·태그·메모는 그대로).
- 다른 PC에서 고친 내용은 이 창으로 돌아올 때 다시 읽어 반영합니다. 두 PC에서 **동시에** 고치면 나중에 저장한 쪽이 남을 수 있습니다.
- 화면 테마, 마지막으로 연 폴더, 최근 검색은 PC마다 따로 둡니다.
- 문서 폴더에 쓸 수 없으면(읽기 전용 공유 폴더 등) 이 PC의 앱 데이터 폴더에 대신 저장합니다. **설정 → 정보**에서 어디에 저장 중인지 볼 수 있습니다.
- 예전 버전이 PC에 저장해 둔 분류 정보는 처음 열 때 자동으로 문서 폴더로 옮깁니다.
- `.docmanager` 폴더를 지우면 직접 고친 분류·태그·메모가 사라집니다. 문서 파일에는 영향이 없습니다.
