# 논문 서재 변경 기록

## 1.5.2

- 설치판(자체 창)에서 논문 제목을 왼쪽 컬렉션으로 끌어다 놓아도 들어가지 않던 문제를 고쳤습니다.
  브라우저 고유의 끌어다 놓기 대신 마우스 움직임을 직접 따라가므로 Windows·macOS·브라우저에서 똑같이 동작합니다.
- 제목 말고도 카드 왼쪽에 마우스를 올리면 나타나는 손잡이(⋮⋮)를 끌어도 됩니다. 끄는 동안 ‘제목 → 컬렉션 이름’이 따라다니고,
  놓을 컬렉션이 파랗게 표시됩니다. Esc로 취소합니다.
- 제목을 누르기만 하면 지금처럼 PDF가 열립니다.

## 1.5.1

**같은 논문의 다른 판 (프리프린트·출판본)**
- arXiv 프리프린트가 있는 논문에 같은 DOI의 출판본 PDF를 넣으면, 버리지 않고 출판본을 본 PDF로 삼고
  서지 정보도 출판본(저널·권·호·쪽)으로 바꿉니다. 이전 PDF는 `논문 이름 - Preprint.pdf`로 바로 옆에 남습니다.
  컬렉션·태그·메모·읽음 상태·별점·딸린 자료는 그대로입니다.
- 반대로 출판본이 있는데 프리프린트를 넣으면 ‘다른 판’으로 붙입니다. 같은 arXiv 논문을 다시 넣으면 중복으로 막습니다.
- 카드에 ‘다른 판’ 줄이 생기고, 수정 창에서 뺄 수 있습니다. 다른 판 PDF의 내용도 검색됩니다.

**중복 의심 · 합치기**
- 제목과 첫 저자가 같은(연도 2년 이내) 항목이 있으면 왼쪽 ‘중복 의심’에 개수가 보입니다.
- 남길 항목을 골라 ‘합치기’를 누르면 컬렉션·태그·메모·읽음 상태·별점·보충자료·정리 자료가 남길 항목으로 모이고,
  나머지 PDF는 지우지 않고 ‘다른 판’으로 붙습니다. 다른 논문이면 ‘중복 아님’으로 목록에서 뺍니다.

## 1.5.0 정식판

1.4.5 정식판 이후에 더해진 기능을 모은 정식판입니다(1.4.6 ~ 1.4.17).

**정리·분류**
- 종류: 학술지 논문 · 학술대회 논문 · 책 · 보고서 · 학위논문 · 기타. 수정 창 맨 위에서 바로 바꿉니다.
- ★ 내 논문·책: 설정의 ‘내 이름’으로 내가 쓴 논문·책을 따로 모아 봅니다.
- 컬렉션: ‘졸업논문’, ‘과제 제안서’처럼 묶음을 만들어 넣습니다(파일은 하나, 여러 컬렉션 가능).
  체크 상자로 여러 편을 고르거나(Shift로 범위, ‘결과 모두 고르기’로 검색 결과 전체), 제목을 왼쪽 컬렉션으로 끌어다 놓아 한꺼번에 넣습니다.
  컬렉션별 보기와 BibTeX 내보내기.
- 읽음 상태(안 읽음 / 읽는 중 / 읽음)와 별점(1~5). 왼쪽 ‘읽기’로 모아 보고 ‘별점’으로 정렬합니다.

**내 정리 자료**
- 논문을 보며 만든 PowerPoint·Word·Excel·한글·메모·그림을 논문에 붙입니다(`논문 이름 - 정리 - 파일 이름`).
  카드의 ‘내 정리’에서 기본 프로그램으로 열고, 안의 글도 검색됩니다.

**추가하기**
- DOI·arXiv ID·ISBN·KCI 논문 ID만으로 서지 정보를 먼저 넣고, 무료 공개 PDF(arXiv·오픈 액세스·출판사 페이지)가 있으면 받아 붙입니다.
  나중에 PDF를 그 카드에 끌어다 놓거나 같은 DOI의 PDF를 넣으면 그 항목에 붙습니다.
- KCI Open API 키를 넣으면 DOI 없는 한글 논문도 제목으로 찾아 학술지·권·호·쪽·초록을 채웁니다.

**화면·속도·안정성**
- 모던 앱형 새 화면(왼쪽 메뉴, 카드 목록, 선 아이콘, 다크 모드, 내장 한글 글꼴).
- 논문이 수천 편이어도 빠르게: 목록은 보는 쪽만, 본문 검색은 데이터베이스 안에서.
- Windows에서 PDF가 다른 프로그램에 열려 있어도 정보는 저장하고, 파일 이름은 닫힌 뒤 자동으로 바꿉니다.
- Windows 업데이트 때 이전 버전 부품을 먼저 지우고 설치합니다(논문·설정은 그대로).

## 1.4.17

- 카드의 읽음 상태를 누를 때마다 바뀌는 단추 대신 목록에서 고르는 상자(안 읽음 / 읽는 중 / 읽음)로 바꿨습니다.
  상태마다 색이 달라(읽는 중 파랑, 읽음 초록) 한눈에 보입니다.

## 1.4.16

**여러 편을 한꺼번에 컬렉션에**
- 카드 왼쪽 위 체크 상자로 논문을 고릅니다. Shift를 누르고 누르면 사이의 것까지 한 번에 고릅니다.
  쪽을 넘기거나 검색어를 바꿔도 고른 것은 유지됩니다.
- 고르면 위에 막대가 나타나 ‘컬렉션에 넣기’(새 컬렉션을 만들며 넣기 포함), ‘이 컬렉션에서 빼기’, ‘읽음 상태’를 한꺼번에 바꿉니다.
- 결과 개수 옆 ‘결과 N편 모두 고르기’로 여러 쪽에 걸친 검색 결과 전체를 고릅니다(예: 검색 → 모두 고르기 → 컬렉션에 넣기).
- 논문 제목을 왼쪽 컬렉션 이름 위로 끌어다 놓으면 그 컬렉션에 들어갑니다. 고른 논문 중 하나를 끌면 고른 것 모두 들어갑니다.
- Esc나 ‘고르기 해제’로 고른 것을 풉니다.

## 1.4.15

**무료 PDF 받기 개선**
- OpenAlex가 PDF 주소 없이 논문 페이지만 알려 주는 경우(예: Nature Communications)에도, 출판사 논문 페이지에 적힌
  PDF 주소(`citation_pdf_url`)를 따라가 받습니다. OpenAlex에 없으면 DOI 페이지에서도 찾아봅니다.
- 브라우저가 아닌 요청을 막는 출판사를 위해 내려받기 요청 형식을 바꿨습니다.
- PDF를 못 받으면 까닭(무료 공개본이 아님·로그인 필요 / 출판사가 자동 내려받기를 막음 등)을 함께 보여 줍니다.

## 1.4.14

**컬렉션(프로젝트별 묶음)**
- 왼쪽 ‘컬렉션’의 ＋로 ‘졸업논문’, ‘과제 제안서’ 같은 묶음을 만들고, 논문 카드의 ‘컬렉션’ 단추로 넣고 뺍니다.
  한 논문을 여러 컬렉션에 넣어도 파일은 하나이고 폴더도 그대로입니다(목록만 묶음).
- 컬렉션을 누르면 그 논문만 보이고, 다른 조건(종류·읽기·검색어)과 함께 걸 수 있습니다.
- 컬렉션 옆 ⋯ 메뉴: 이름 바꾸기, 이 컬렉션만 BibTeX 내보내기, 지우기(논문은 남음).

**읽음 상태·별점**
- 카드 오른쪽 아래에서 안 읽음 → 읽는 중 → 읽음을 누를 때마다 바꾸고, 별 1~5개를 매깁니다(같은 별을 다시 누르면 지움).
- 왼쪽 ‘읽기’에서 상태별로 모아 보고, 정렬에 ‘별점’이 생겼습니다.

**국내 논문 정보 (KCI)**
- 설정에 KCI Open API 키(open.kci.go.kr에서 무료 발급)를 넣으면, DOI가 없는 한글 논문도 제목으로 KCI에서 찾아
  학술지·권·호·쪽·초록을 채웁니다. 한글 제목은 KCI를 먼저, 영어 제목은 Crossref를 먼저 찾습니다.
- 수정 창의 ‘제목으로 찾기’에 KCI 후보가 함께 나오고, KCI 논문 ID(ART…)로도 가져올 수 있습니다.
- 설정의 ‘확인’ 단추로 키가 맞는지 바로 시험합니다.

**PDF 없이 추가 + 무료 PDF 받기**
- 왼쪽 ‘DOI·ISBN으로 추가’에 DOI·arXiv ID·ISBN·KCI 논문 ID를 한 줄에 하나씩(여러 개 가능) 넣으면 서지 정보만 먼저 등록합니다.
- arXiv나 오픈 액세스(OpenAlex가 알려 주는 무료 공개본)에 PDF가 있으면 받아서 바로 붙입니다.
- PDF가 없는 항목은 ‘PDF 없음’으로 보이고, 나중에 PDF를 그 카드 위에 끌어다 놓거나 수정 창에서 고르면 붙습니다.
  같은 DOI·ISBN의 PDF를 빈 곳에 넣어도 그 항목에 붙습니다. 카드의 ‘무료 PDF 찾기’로 다시 찾을 수도 있습니다.

## 1.4.13

**내 정리 자료 붙이기**
- 논문을 보며 만든 PowerPoint·Word·Excel·한글(hwp/hwpx)·메모(txt, md)·그림 등을 논문에 붙여 둘 수 있습니다.
  - 목록의 논문 위에 끌어다 놓거나, 수정 창 아래 ‘내 정리 자료 → 파일 추가’로 넣습니다.
  - 빈 곳에 놓거나 ‘파일 추가’로 고르면 어느 논문의 정리 자료인지 묻습니다(함께 넣은 논문 PDF가 하나면 그 논문).
  - 수정 창의 ‘파일 추가’로는 PDF도 정리 자료로 붙일 수 있습니다(예: 주석 단 사본).
- 논문 바로 옆에 `논문 이름 - 정리 - 원래 파일 이름.pptx`로 복사해 둡니다. 논문 이름이 바뀌면 따라 바뀌고,
  논문을 서재에서 빼면 함께 휴지통 폴더(.papershelf/trash)로 갑니다.
- 카드에 ‘내 정리’ 줄이 생기고(PPTX·DOCX 같은 색 배지), 누르면 PowerPoint·Word 등 기본 프로그램으로 엽니다.
- Word·PowerPoint(발표자 메모 포함)·Excel·hwpx·텍스트 안의 글도 검색되며, 걸리면 `내 정리` 표시와 함께 그 대목이 보입니다.
- 폴더에 직접 넣은 `논문 이름 - 정리 - ….확장자` 파일도 ‘폴더 다시 읽기’ 때 붙습니다.
- 실행 파일(exe, bat 등)은 받지 않습니다.

## 1.4.12

**PDF가 열려 있을 때 (Windows)**
- 그 PDF를 Acrobat·Edge 등에서 열어 둔 채 정보를 고치거나 DOI로 다시 받아오면, 파일 이름을 못 바꿔
  저장 전체가 취소되던 문제(WinError 32)를 고쳤습니다. 이제 서지 정보는 먼저 저장하고, 파일 이름은
  ‘이름 바꾸기 대기’로 표시했다가 PDF를 닫으면 1분 안에 자동으로 바꿉니다(앱을 다시 켤 때도 시도).
- 열려 있는 PDF를 서재에서 지우려 하면 일부만 휴지통으로 옮겨지지 않도록 아무것도 지우지 않고 안내합니다.

## 1.4.11

**학위논문(Thesis) 종류 추가**
- 왼쪽 서재 목록과 수정 창 분류에 ‘학위논문’이 생겼습니다(졸업모자 아이콘).
- 목록에는 `저자 · 연도 · 학교`로 보이고, 수정 창의 저널 칸은 ‘학교’로 바뀝니다.
- 인용: APA `[Doctoral dissertation, 학교]`, MLA `학교, PhD dissertation.`, BibTeX `@phdthesis`.
- 온라인 정보가 없을 때 ‘dissertation’, ‘thesis submitted’, ‘in partial fulfillment’, ‘학위논문’, ‘박사/석사 학위’ 같은
  표현이 앞부분에 있으면 학위논문으로 봅니다(쪽수가 많아도 책으로 잘못 분류하지 않음).

## 1.4.10

**논문이 많아도 빠르게**
- 목록을 열 때 논문 본문 전체를 불러오지 않습니다. 본문 검색은 데이터베이스 안에서 하고 걸린 대목만 꺼냅니다.
- 화면에는 지금 보는 쪽(10~50개)만 받아 옵니다.
- 시험용 논문 5,000편(본문 포함 약 360MB) 기준: 목록 2.1초 → 0.2초, 전체 검색 1.05초 → 0.57초.
- 검색 결과가 1,000개를 넘으면 뒤쪽 쪽이 비던 문제를 고쳤습니다.

## 1.4.9

- ‘★ 내 논문·책’을 누르면 종류 선택을 ‘전체’로 되돌려 내 것 전부가 바로 보입니다
  (전에는 다른 종류가 선택된 채로 겹쳐 걸려 0개가 나올 수 있었음).
- 내 논문·책을 보는 동안 종류별 개수도 내 것 기준으로 보이고, 내 것이 없는 종류는 숨깁니다.
- 걸러서 0개일 때 걸린 조건을 보여 주고 ‘조건 모두 풀기’ 버튼을 둡니다.

## 1.4.8

**새 화면 (모던 앱형)**
- 왼쪽에 꽉 찬 메뉴 패널: 파일 추가, 서재(내 논문·책, 전체, 학술지·학술대회·책·보고서·기타와 개수), 기간,
  아래쪽 도구(폴더 다시 읽기, 인용 수 새로 고침, BibTeX 내보내기, 논문 폴더 열기, 설정).
- 위쪽 도구 막대: 큰 검색창, 정렬 단추, ‘보기’ 팝업(한 화면 개수, 초록, 확인 필요한 것만).
- 논문은 둥근 카드로: 종류 배지(색·아이콘), 제목, 저자·저널, 초록, 보충자료, 인용 수·인용·수정 등.
- 이모지 대신 선 아이콘, 마우스 올림 효과, 빈 서재·검색 결과 없음 그림, 다크 모드 색 다듬기, 새 앱 아이콘.
- 한글 글꼴(Pretendard)을 앱 안에 넣어 오프라인에서도 같은 모양으로 보입니다.

## 1.4.7

- Windows 설치 파일로 업데이트할 때 이전 버전의 내부 부품을 먼저 지우고 새로 넣습니다.
  논문 폴더·목록·설정은 그대로 남습니다.

## 1.4.6

**분류 늘리기**
- 수정 창 맨 위 분류에서 학술지 논문 · 학술대회 논문 · 보고서 · 책 · 기타 · 보충자료를 바로 고릅니다.
- 왼쪽 종류 필터: 전체 / 학술지 논문 / 학술대회 논문 / 책 / 보고서 / 기타, 종류별 개수 표시.
- 보고서는 `저자 - 연도 - 발행 기관`으로 보이고, 인용은 APA `(Report No. …)`·BibTeX `@techreport` 형식.
  학술대회 논문은 `In 논문집 이름 (pp. …)` 형식.
- 온라인에서 정보를 못 찾았을 때 첫 페이지에 ‘Proceedings of …’, ‘학술대회’가 있으면 학술대회 논문,
  ‘Technical Report’, ‘연구보고서’가 있으면 보고서로 짐작합니다.

**내 논문·책**
- 설정에 ‘내 이름(저자 표기)’을 적으면(예: `Gildong Hong; G. Hong; 홍길동`) 저자에 내 이름이 있는
  논문·책에 ★ 내 저작 표시가 붙고, 왼쪽 ‘★ 내 논문·책’으로 따로 모아 볼 수 있습니다.
- 수정 창의 ‘★ 내 논문·책’으로 직접 켜고 끌 수 있습니다(직접 정한 값이 자동 판단보다 우선).

## 1.4.5 정식판

**보충 동영상**
- 동영상(mp4, mov, m4v, avi, mkv, webm, wmv 등)도 끌어다 놓으면 본문 논문에 묶어
  `본문 이름 - Supplementary Video.mp4`(여러 개면 `… Video 2.mp4`)로 저장합니다.
- 어느 논문에 묶을지:
  - 논문 위에 끌어다 놓으면 그 논문.
  - 논문 PDF와 함께 넣으면 그 논문(함께 넣은 논문이 여럿이면 물어봄).
  - `…_MOESM2_ESM.mp4`, `…-mmc2.mp4`처럼 출판사 번호가 같은 보충자료 PDF가 이미 있으면 그 논문.
  - 그래도 모르면 올리기 전에 논문을 고르는 창을 띄웁니다.
- 목록의 보충자료 칸에 🎬 표시로 보이고, 누르면 기본 동영상 프로그램(브라우저 모드에서는 새 탭)으로 재생합니다.
- 본문 논문의 이름이 바뀌면 동영상 이름도 따라 바뀌고, 본문을 지우면 함께 휴지통 폴더로 갑니다.
- 수정 창 아래 보충자료 목록에서 잘못 묶인 보충자료를 하나씩 뺄 수 있습니다.
- 폴더에 직접 넣은 동영상도 이름이 본문 파일 이름으로 시작하면 ‘폴더 다시 읽기’ 때 묶습니다.

## 1.4.0 정식판

**브라우저 없이 독립 프로그램 창으로 실행**
- 크롬·엣지 브라우저를 열지 않고 ‘논문 서재’ 자체 창으로 뜹니다(주소창·탭 없음). 창을 닫으면 프로그램이 끝납니다.
  화면은 운영체제에 들어 있는 엔진(Windows: Edge WebView2, macOS: WebKit)으로 그립니다.
- 논문 제목·[PDF]를 누르면 컴퓨터의 기본 PDF 프로그램(Acrobat, 미리보기 등)으로 엽니다.
  DOI·인용 목록 같은 바깥 링크는 기본 브라우저로 엽니다.
- BibTeX 내보내기는 저장 위치를 묻는 창으로 저장합니다.
- 이미 켜져 있을 때 다시 실행하면 기존 창을 앞으로 불러옵니다.
- Windows 자동 실행을 고르면 최소화한 채로 시작합니다.
- WebView2가 없는 오래된 Windows에서는 예전처럼 브라우저로 엽니다. `--browser`로 브라우저 모드를 고를 수도 있습니다.

## 1.3.0 정식판

내 컴퓨터의 논문·책 PDF를 Google Scholar처럼 정리하고 검색하는 앱의 첫 정식판입니다.

**정리**
- PDF를 끌어다 놓으면 DOI·arXiv ID·제목으로 Crossref·arXiv에서 서지 정보를 찾아
  `저자 et al. - 연도 - 제목.pdf` 이름으로 논문 폴더에 저장합니다.
- 책은 판권 면의 ISBN으로 Crossref·Google Books·Open Library에서 제목·저자(편집자)·출판사·판을 찾습니다.
- 보충자료(Supplementary)는 본문에 묶어 `본문 이름 - Supplementary.pdf`로 저장합니다.
  논문 위에 끌어다 놓으면 그 논문의 보충자료가 됩니다.
- 같은 파일이나 같은 DOI는 다시 넣지 않습니다. 못 찾은 정보는 ‘확인 필요’로 표시합니다.

**보기·검색**
- 제목 / `저자 - 저널, 연도 - 출판사` / 초록의 Scholar 형식 목록.
- 제목·저자·저널·본문 검색, 기간·종류(논문/책) 필터, 관련도·인용·추가·연도·제목순 정렬.
- 한 화면에 10~50개, 쪽 나누기. 초록 숨김/짧게/전체.
- 인용 수(OpenAlex·Semantic Scholar·Crossref)와 인용한 문헌 목록 링크. 30일마다 자동 갱신.

**그 밖에**
- APA·MLA·BibTeX 인용 복사, BibTeX 전체 내보내기.
- 수정 창에서 DOI·arXiv ID·ISBN으로 다시 받아오기, 제목으로 Crossref·Google Books 후보 고르기.
- Windows 설치 파일과 macOS 앱(Apple 칩·Intel). 알림 영역·메뉴 막대 아이콘.
