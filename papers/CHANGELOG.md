# 논문 서재 변경 기록

## 1.4.9

- ‘★ 내 논문·책’을 누르면 종류 선택을 ‘전체’로 되돌려 내 것 전부가 바로 보입니다
  (전에는 다른 종류가 선택된 채로 겹쳐 걸려 0개가 나올 수 있었음).
- 내 논문·책을 보는 동안 종류별 개수도 내 것 기준으로 보이고, 내 것이 없는 종류는 숨깁니다.
- 걸러서 0개일 때 걸린 조건을 보여 주고 ‘조건 모두 풀기’ 버튼을 둡니다.

## 1.4.8

**새 화면 (모던 앱형)**
- 왼쪽에 꽉 찬 메뉴 패널: 파일 추가, 서재(내 논문·책, 전체, 학술지·학술대회·책·보고서·기타와 개수), 기간,
  아래쪽 도구(폴더 다시 읽기, 인용 수 새로 고침, BibTeX 내보내기, 논문 폴더 열기, 설정).
- 위쪽 도구 막대: 큰 검색창, 정렬 단추, ‘보기’ 팝업(한 화면 개수, 초록, 확인 필요한 것만).
- 논문은 둥근 카드로: 종류 배지(색·아이콘), 제목, 저자·저널, 초록, 보충자료, 인용 수·인용·수정 등.
- 이모지 대신 선 아이콘, 마우스 올림 효과, 빈 서재·검색 결과 없음 그림, 다크 모드 색 다듬기, 새 앱 아이콘.
- 한글 글꼴(Pretendard)을 앱 안에 넣어 오프라인에서도 같은 모양으로 보입니다.

## 1.4.7

- Windows 설치 파일로 업데이트할 때 이전 버전의 내부 부품을 먼저 지우고 새로 넣습니다.
  논문 폴더·목록·설정은 그대로 남습니다.

## 1.4.6

**분류 늘리기**
- 수정 창 맨 위 분류에서 학술지 논문 · 학술대회 논문 · 보고서 · 책 · 기타 · 보충자료를 바로 고릅니다.
- 왼쪽 종류 필터: 전체 / 학술지 논문 / 학술대회 논문 / 책 / 보고서 / 기타, 종류별 개수 표시.
- 보고서는 `저자 - 연도 - 발행 기관`으로 보이고, 인용은 APA `(Report No. …)`·BibTeX `@techreport` 형식.
  학술대회 논문은 `In 논문집 이름 (pp. …)` 형식.
- 온라인에서 정보를 못 찾았을 때 첫 페이지에 ‘Proceedings of …’, ‘학술대회’가 있으면 학술대회 논문,
  ‘Technical Report’, ‘연구보고서’가 있으면 보고서로 짐작합니다.

**내 논문·책**
- 설정에 ‘내 이름(저자 표기)’을 적으면(예: `Gildong Hong; G. Hong; 홍길동`) 저자에 내 이름이 있는
  논문·책에 ★ 내 저작 표시가 붙고, 왼쪽 ‘★ 내 논문·책’으로 따로 모아 볼 수 있습니다.
- 수정 창의 ‘★ 내 논문·책’으로 직접 켜고 끌 수 있습니다(직접 정한 값이 자동 판단보다 우선).

## 1.4.5 정식판

**보충 동영상**
- 동영상(mp4, mov, m4v, avi, mkv, webm, wmv 등)도 끌어다 놓으면 본문 논문에 묶어
  `본문 이름 - Supplementary Video.mp4`(여러 개면 `… Video 2.mp4`)로 저장합니다.
- 어느 논문에 묶을지:
  - 논문 위에 끌어다 놓으면 그 논문.
  - 논문 PDF와 함께 넣으면 그 논문(함께 넣은 논문이 여럿이면 물어봄).
  - `…_MOESM2_ESM.mp4`, `…-mmc2.mp4`처럼 출판사 번호가 같은 보충자료 PDF가 이미 있으면 그 논문.
  - 그래도 모르면 올리기 전에 논문을 고르는 창을 띄웁니다.
- 목록의 보충자료 칸에 🎬 표시로 보이고, 누르면 기본 동영상 프로그램(브라우저 모드에서는 새 탭)으로 재생합니다.
- 본문 논문의 이름이 바뀌면 동영상 이름도 따라 바뀌고, 본문을 지우면 함께 휴지통 폴더로 갑니다.
- 수정 창 아래 보충자료 목록에서 잘못 묶인 보충자료를 하나씩 뺄 수 있습니다.
- 폴더에 직접 넣은 동영상도 이름이 본문 파일 이름으로 시작하면 ‘폴더 다시 읽기’ 때 묶습니다.

## 1.4.0 정식판

**브라우저 없이 독립 프로그램 창으로 실행**
- 크롬·엣지 브라우저를 열지 않고 ‘논문 서재’ 자체 창으로 뜹니다(주소창·탭 없음). 창을 닫으면 프로그램이 끝납니다.
  화면은 운영체제에 들어 있는 엔진(Windows: Edge WebView2, macOS: WebKit)으로 그립니다.
- 논문 제목·[PDF]를 누르면 컴퓨터의 기본 PDF 프로그램(Acrobat, 미리보기 등)으로 엽니다.
  DOI·인용 목록 같은 바깥 링크는 기본 브라우저로 엽니다.
- BibTeX 내보내기는 저장 위치를 묻는 창으로 저장합니다.
- 이미 켜져 있을 때 다시 실행하면 기존 창을 앞으로 불러옵니다.
- Windows 자동 실행을 고르면 최소화한 채로 시작합니다.
- WebView2가 없는 오래된 Windows에서는 예전처럼 브라우저로 엽니다. `--browser`로 브라우저 모드를 고를 수도 있습니다.

## 1.3.0 정식판

내 컴퓨터의 논문·책 PDF를 Google Scholar처럼 정리하고 검색하는 앱의 첫 정식판입니다.

**정리**
- PDF를 끌어다 놓으면 DOI·arXiv ID·제목으로 Crossref·arXiv에서 서지 정보를 찾아
  `저자 et al. - 연도 - 제목.pdf` 이름으로 논문 폴더에 저장합니다.
- 책은 판권 면의 ISBN으로 Crossref·Google Books·Open Library에서 제목·저자(편집자)·출판사·판을 찾습니다.
- 보충자료(Supplementary)는 본문에 묶어 `본문 이름 - Supplementary.pdf`로 저장합니다.
  논문 위에 끌어다 놓으면 그 논문의 보충자료가 됩니다.
- 같은 파일이나 같은 DOI는 다시 넣지 않습니다. 못 찾은 정보는 ‘확인 필요’로 표시합니다.

**보기·검색**
- 제목 / `저자 - 저널, 연도 - 출판사` / 초록의 Scholar 형식 목록.
- 제목·저자·저널·본문 검색, 기간·종류(논문/책) 필터, 관련도·인용·추가·연도·제목순 정렬.
- 한 화면에 10~50개, 쪽 나누기. 초록 숨김/짧게/전체.
- 인용 수(OpenAlex·Semantic Scholar·Crossref)와 인용한 문헌 목록 링크. 30일마다 자동 갱신.

**그 밖에**
- APA·MLA·BibTeX 인용 복사, BibTeX 전체 내보내기.
- 수정 창에서 DOI·arXiv ID·ISBN으로 다시 받아오기, 제목으로 Crossref·Google Books 후보 고르기.
- Windows 설치 파일과 macOS 앱(Apple 칩·Intel). 알림 영역·메뉴 막대 아이콘.
