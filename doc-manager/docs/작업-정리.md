# 워크데스크 — 지금까지 정리 (2026-10-10)

예전 이름은 '문서 보관함'입니다. 이 문서는 지금까지 대화로 정한 것과 만든 것을 한곳에 모은 기록입니다.
기능 사용법은 저장소 맨 위 `README.md`의 `doc-manager/` 부분에 있습니다.

## 1. 무엇을 하는 앱인가

- 회사 업무 문서(국가과제·지원사업, IR·회사소개, 홍보, 기술·시장 분석, 고객사, 구매·견적, 회사 증빙, 지식재산)를 한 폴더에 모아 두면 **자동으로 분류·태그·버전 묶기**를 합니다.
- **Claude 커넥터**(MCP)로 Claude 데스크톱이 문서를 읽고, 새 문서를 씁니다.
- 최종 목표: Claude가 아래 자료를 읽고 **수요조사서·사업계획서를 우리 회사답게** 쓰는 것입니다.
  - 회사 지식 카드
  - 주제·사업 카드
  - 작성 가이드
  - 지원 이력
  - 공고문 같은 사업 자료

## 2. 꼭 지키는 원칙 (사용자와 정한 것)

| 원칙 | 내용 |
|---|---|
| 원본 보호 | 사용자 문서를 덮어쓰거나 지우지 않는다. Claude가 고친 것은 **새 버전 파일**로 저장한다. |
| 지우기 | 앱에서 사용자가 누를 때만, **휴지통**으로 보낸다. |
| AI 제외 | 'AI제외' 태그·제외 분류 문서는 Claude가 절대 못 본다. |
| 개인정보 | 등기부등본·주주명부·인사 민감 서류(근로·연봉계약, 급여명세, 원천징수, 인사기록)와 주민번호가 보이는 문서는 **처음부터 AI제외**. |
| 기록 | Claude가 무엇을 읽고 썼는지 활동 기록을 남긴다. |
| 알림 범위 | 특허 **연차료 알림은 하지 않는다** (특허 사무소가 알려 줌). |
| 기본 화면 | 문서 목록은 **보통 보기가 기본**, 촘촘 보기는 선택. |

## 3. 만든 기능 (영역별)

### 문서 정리
- 자동 분류(파일 이름 → 폴더 → 본문 순 점수). 분류 근거를 보여 주고, 직접 고칠 수 있다. 분류 키워드도 편집할 수 있다.
- 분류 묶음:
  - 국가과제·지원사업 (단계 1~6)
  - 회사 증빙: 기본 서류 · 인증·확인서 · 실적·재무 · **인사**
  - 지식재산: 특허 출원 · 특허 등록 · 상표·디자인
  - 회사소개, 홍보, 기술·시장 분석, 고객사·협력사, 구매·견적
- 문서 처리:
  - YYMMDD 날짜와 기술 분야 태그
  - 같은 문서의 여러 버전 묶기와 버전 비교
  - 제자리로 옮기기, 중복 정리, 형식 바꾸기(hwp→hwpx 등)
- 읽을 수 있는 형식: hwp, hwpx, docx, pptx, xlsx, pdf
  - **스캔 PDF는 윈도우 글자 인식(OCR)**으로 읽는다.
  - **글자가 깨진 PDF**(홈택스 표준재무제표 등)도 알아채서 OCR로 다시 읽는다.

### 업무
- **할 일** (앱을 켜면 첫 화면)
  - 카드: 다가오는 마감, 만료되는 증빙, 대장에 없는 지식재산 번호, 정리할 문서, 스캔 PDF, 아직 없는 작성 카드, 이번 주 문서, 최근 Claude 활동
  - ✓ 확인함 / 모두 확인함 / 다시 보기
- **지원 현황**
  - 사업명별로 묶고, 지원 건마다 단계(마감일·결과·메모)를 기록한다.
  - 사업 자료(공고문·RFP·양식·평가 기준)를 붙이고, 과제만의 자료도 따로 붙인다.
  - 마감 알림(7·3·1일 전·당일), 캘린더(.ics·구글) 내보내기
  - 제출 서류 꾸러미: 증빙 최신본을 한 폴더에 모아 준다.
- **지식재산 대장**
  - 특허·실용신안·디자인·상표를 관리한다.
  - 문서에서 그 문서 **자신의** 출원번호를 찾아 넣자고 제안한다.
  - 표로 복사하기
- **회사 증빙**
  - 종류와 최신본을 알아본다.
  - 발급일·유효기간: 유효기간이 없는 서류는 만료일로 보지 않고, '유효기간 없음' 체크도 있다.
  - 만료 알림: 30·7일 전, 당일

### Claude와 함께 쓰기
- 커넥터 연결: 설정 → Claude 연결. 앱을 켤 때 실행 파일이나 데이터 폴더가 바뀌었으면 연결 설정을 저절로 고친다.
- 카드: **회사 지식 카드**, **주제 카드**, **사업 카드**, **작성 가이드 2종(수요조사서 / 사업계획서)**
  - 저장 위치: 문서 폴더의 `Claude 지식/`
  - 사용자 메모 칸은 Claude가 건드리지 않는다.
- 지원 건의 **문서 쓰기** 탭: Claude에게 붙여 넣을 요청 문장을 만든다. Claude는 이 순서로 읽는다.
  1. 지식 카드
  2. 이력·탈락 사유
  3. 사업 자료
  4. 카드
  5. 양식
- 양식 채우기: 표 행 추가, 체크박스

### 화면
- 왼쪽 메뉴: **업무 / 문서 / 분류**
  - 과제·연도·형식·태그·키워드는 **거르기** 버튼에 있다.
  - 메뉴 **접기**: 아이콘 줄. 창 너비가 1100px 미만이면 저절로 접힌다.
- 문서 목록: **촘촘 보기**를 고를 수 있다.
- 오른쪽 칸 탭:
  - 문서: 개요 / 연결 / 내용
  - 지원 건: 단계 / 자료 / 문서 쓰기 / 정보
- 단계 카드는 촘촘하게 보이고, 메모는 '+ 메모'로 열고 닫는다.

## 5. 겪은 문제와 배운 점

| 문제 | 원인 | 고친 것 |
|---|---|---|
| 앱 이름을 바꾼 뒤 문서 폴더를 다시 물어봄 | 앱 데이터 폴더는 `package.json`의 `name`(**doc-manager**)으로 정해진다. `build.productName`과는 상관없다. | 이름 변경 후에도 `doc-manager` 폴더를 쓴다. **`name`은 바꾸지 말 것.** |
| 재무제표가 '만료됨'으로 뜸 | 본문의 사업연도 끝(…12.31까지)을 유효기간으로 읽음 | 유효기간이 없는 서류는 본문 날짜를 보지 않는다. '유효기간 없음' 체크를 추가했다. |
| 대장에 없는 지식재산 번호 41개 | 명세서의 선행기술 번호까지 잡음 | 파일 이름, '출원번호'·(21) 칸, 문서 첫머리의 번호만 본다. |
| 표준재무제표 글자가 깨짐 | PDF 글꼴 정보가 없다 | 깨짐을 알아채서 OCR로 읽는다. Claude에게는 깨진 글자를 보내지 않는다. |
| OCR이 한글을 한 글자씩 띄움 | 글자 간격을 띄어쓰기로 봄 | 글자 높이에 비해 간격이 넓을 때만 띄우고, 흩어진 한글은 붙인다. |
| 시작할 때 오류(renderTodoView) | 스크립트를 읽는 순서 | 함수가 있는지 확인하고, 다 읽은 뒤 다시 그린다. |
| 같은 이름 함수가 겹쳐 화면이 멈춤 | 화면 스크립트들이 같은 전역 공간을 씀 | 이름을 바꾸고, 겹치는 이름을 잡는 테스트를 추가했다. |
