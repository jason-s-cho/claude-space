문서를 한곳에서 찾고 정리하세요

문서를 모아 둘 폴더를 고르면, 워드·파워포인트·엑셀·PDF·한글 파일을 읽어서
국가과제·IR·홍보·기술분석·고객사 자료 등으로 자동 분류하고 태그를 붙입니다.

  • 분류별 폴더를 만들고, 새 문서는 끌어다 놓기만 하면 정리됩니다
  • 본문까지 검색하고, 같은 문서의 여러 버전을 묶어 최신본을 보여 줍니다
  • 이미 있는 파일은 옮기거나 고치지 않습니다

    설정

    일반

    화면 테마
    끌어다 놓은 파일 저장 위치 원본은 그대로 두고 복사합니다. 같은 이름이면 "이름 (2)"로 저장하고, 내용까지 같은 파일은 다시 넣지 않습니다. 분류별 정리를 고르면 분류 폴더를 미리 만들어 둡니다.

    과제

    진행했거나 진행 중인 국가과제·지원사업을 적어 두면, 파일 이름·폴더 이름·문서 첫머리에서 과제 이름을 찾아 과제 폴더(국가과제·지원사업 / 과제 이름 / 단계)로 정리하고 과제 태그를 붙입니다.

    과제 폴더 아래 단계: 1 공고·수요조사 · 2 사업계획서 · 3 선정·협약 · 4 수행·회의 · 5 보고서 · 6 정산·증빙

    고객사 · 태그

    분류 키워드

    문서에서 키워드를 찾으면 그 분류 점수를 올립니다. 파일 이름에 있으면 4배, 폴더 이름은 3배, 본문 앞부분은 1배로 셉니다. '강함'은 파일 이름에 한 번만 나와도 그 분류로 정해질 정도입니다.

    Claude 연결

    Claude 데스크톱 앱(또는 Claude Code)에서 이 보관함을 쓸 수 있게 연결합니다. 연결하면 Claude 에게 "작년 K-방산 최종보고서에서 성과 부분 찾아서 올해 계획서에 맞게 고쳐 줘"처럼 말할 수 있습니다. Claude 는 문서를 찾고 읽고, 고친 결과를 새 버전 파일로만 저장합니다. 기존 파일을 고치거나 지울 수는 없습니다.

    Claude 데스크톱 앱
    확인 중…
    연결하거나 해제한 뒤에는 Claude 데스크톱 앱을 완전히 종료했다가 다시 켜야 적용됩니다. (작업 표시줄 알림 영역의 Claude 아이콘 → 종료) 기존 Claude 설정은 .bak 파일로 남겨 둡니다.
    회사 지식 카드 Claude 가 문서를 쓰기 전에 먼저 읽는 회사 핵심 사실
    확인 중…
    문서 보관함의 자료로 회사 지식 카드를 만들어 줘
    위 문장을 Claude 데스크톱 일반 채팅에 붙여 넣으면 Claude 가 보관함 문서를 읽고 카드를 만들어 Claude 지식/회사 지식 카드.md 에 저장합니다. 문서가 늘면 "회사 지식 카드 새로 고쳐 줘"라고 하면 됩니다. 이전 내용은 자동으로 보관하고, 맨 아래 사용자 메모는 Claude 가 고치지 않습니다.
    Claude Code 에서 쓰기 터미널에 한 번 붙여 넣기
    Claude 에 보내지 않을 문서
    고른 분류의 문서와, 문서 오른쪽에서 Claude 에 보내지 않기를 켠 문서('AI제외' 태그)는 Claude 가 검색하거나 읽을 수 없습니다.

        중복 정리

        내용이 완전히 같은 파일들입니다. 묶음마다 남길 파일 하나를 고르면 나머지는 휴지통으로 보냅니다 (휴지통에서 되살릴 수 있습니다). 사본에 붙인 태그·메모는 남길 파일로 옮겨 붙입니다. 보내기 직전에 내용이 같은지 한 번 더 확인합니다. 정리하지 않을 묶음은 체크를 빼세요.
